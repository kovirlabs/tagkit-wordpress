TagKit for WordPress

A plain, fast, accessible block theme

Your posts and pages are semantic HTML styled by TagBrush.css. Light and dark mode follow each reader's system, and one color themes the whole site.

Install the theme Source on GitHub

What you get

  • Templates for the posts list (cards in a grid), single posts, pages, archives, search, and 404.
  • A header and a footer you can edit in the Site Editor.
  • One Primary color in the Site Editor themes links, buttons, accents, and tints, readable in light and dark mode. Fonts work the same way.
  • Styles for content from the classic editor (captions, alignments) and from every core block. No page scrolls sideways on a phone.
  • TagAction makes code blocks copyable, tables sortable, and headings linkable. It only loads on pages with code, tables, details, forms, or comments.
  • Everything works with JavaScript turned off.

This theme is one of TagKit's themes. TagKit's gallery has page templates and snippets to copy, plus themes for Jekyll, MkDocs, Hugo, and Pandoc.

Install

  1. Download tagkit.zip from the releases page.
  2. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
  3. Choose the zip, install it, and activate TagKit.

Version 0.1.0 is not released yet. Until it is, download tagkit.zip from the latest CI run, or build it from the source:

npm install
npm run zip

The zip lands in dist/tagkit.zip and holds only the files WordPress needs.

Templates, parts, and patterns

Edit any of them in Appearance > Editor.

Templates
TemplateWhat it shows
indexThe posts list: cards in a grid with a featured image, title, excerpt, and date.
singleOne post with its author, date, categories, tags, previous and next links, and comments.
pageA page with its title, featured image, and content.
archiveA category, tag, author, or date archive, as cards.
searchSearch results, as cards, with a search box.
404A "Page not found" message.
Header part
The site title and the navigation menu.
Footer part
The site tagline and a credit line.
Patterns
Footer credit, No results, and Page not found. The templates use them to hold translatable text. They don't appear in the block inserter.

One color themes the site

Go to Appearance > Editor > Styles > Colors and change Primary. TagBrush.css works out readable text, hover, and dark mode colors from it.

theme.json maps Primary into TagBrush.css's --color-primary, sets the content width to TagBrush.css's reading width, and styles WordPress's buttons with TagBrush.css's button colors. The default Primary is #2563eb.

To turn off TagAction, add this to a plugin or a child theme:

add_filter( 'tagkit_load_tagaction', '__return_false' );

Requirements

WordPress
6.6 or later. Tested up to 7.1.
PHP
7.4 or later.

TagBrush.css and TagAction ship inside the theme, so it loads nothing from a CDN.

Status

Version 0.1.0 is the first version and is not released yet. It bundles TagBrush.css 1.2.0 and TagAction 0.1.0 and is tested with WordPress 7.1.

Tests run against a WordPress in Docker with the Theme Unit Test content. They check that no page scrolls sideways at a 360px phone width, that text the theme colors meets WCAG AA contrast in light and dark mode, that the theme's own pages have no TagCheck errors, that TagAction loads only where it's used, and that the Primary color drives TagBrush.css. CI runs them, and WordPress's Theme Check, against the release zip.
